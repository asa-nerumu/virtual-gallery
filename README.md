# バーチャル展覧会「MUSEUM OF FORMS」公開・セットアップ手順書

この手順書では、`virtual_gallery.html` をインターネット上に公開し、**管理者が設置・公開した作品を URL 共有だけで全鑑賞者のブラウザへリアルタイム反映させる**ためのセットアップ手順を解説します。

サーバー代は基本的に **無料（Firebase 無料枠＋無料ホスティング）** で運用できます。

---

## 全体の流れ（所要時間：約10〜15分）

1. **Step 1：Firebase でデータ保存先（クラウド）を作る**（約5〜8分）
2. **Step 2：`virtual_gallery.html` に設定をコピペする**（約2分）
3. **Step 3：無料ホスティングにアップロードして URL を発行する**（約2分）
4. **Step 4：管理者ログインしてパスワードを変更・作品を設置する**（約2分）

---

## Step 1：Firebase プロジェクトの準備（無料）

作品の画像データ・タイトル・公開設定・鑑賞者コメントを保存するため、Google の **Firebase（Spark プラン：無料）** を設定します。

### 1-1. プロジェクトを作成する
1. [Firebase Console](https://console.firebase.google.com/) に Google アカウントでログインします。
2. **「プロジェクトを作成」** をクリックし、任意の名前（例：`my-virtual-gallery`）を入力して続行します。
3. Google アナリティクスはオフのままで構いません。**「プロジェクトを作成」** を押して完了するまで待ちます。

### 1-2. ウェブアプリを登録して設定値（Config）を取得する
1. プロジェクトの概要画面で、ウェブアイコン **`</>`** をクリックします。
2. アプリのニックネーム（例：`gallery-web`）を入力し、**「アプリを登録」** をクリックします（※Firebase Hosting のチェックは不要です）。
3. 画面に表示される `firebaseConfig` の **`{ ... }` 部分** をコピーしてメモしておきます。

```javascript
// この { から } までをメモしておきます
{
  apiKey: "AIzaSy...",
  authDomain: "〇〇.firebaseapp.com",
  projectId: "〇〇",
  storageBucket: "〇〇.firebasestorage.app",
  messagingSenderId: "〇〇",
  appId: "1:〇〇:web:〇〇"
}
```

### 1-3. 匿名認証（Authentication）を有効にする
鑑賞者や管理者が安全にクラウドへ接続できるよう、匿名認証をオンにします。

1. 左メニューの **「構築」＞「Authentication」** を開き、**「始める」** をクリックします。
2. **「Sign-in method」** タブから **「匿名」** を選択します。
3. **「有効にする」** をオンにして **「保存」** をクリックします。

### 1-4. データベース（Cloud Firestore）を作成する
1. 左メニューの **「構築」＞「Firestore Database」** を開き、**「データベースの作成」** をクリックします。
2. ロケーションは **`asia-northeast1`（東京）** などを選択して「次へ」を押します。
3. セキュリティルールは **「本番環境モードで開始」** または **「テストモードで開始」** を選んで作成します。
4. 作成後、上部タブの **「ルール」** を開き、以下のルールに書き換えて **「公開」** をクリックします。

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // 匿名認証済みのユーザーに展覧会データの読み書きを許可
    match /artifacts/{appId}/public/data/{collection}/{document} {
      allow read, write: if request.auth != null;
    }
  }
}
```

## Step 2：`virtual_gallery.html` に Firebase 設定を書き込む

1. `virtual_gallery.html` をパソコンに保存します。
   - 公開時にトップページとして認識されやすいよう、ファイル名を **`index.html`** に変更しておくのがおすすめです。
2. メモ帳や VS Code などのテキストエディタでファイルを開きます。
3. ファイル内の **`★ 公開用設定エリア（ここだけ書き換えればOK！）`** を検索します。
4. `const USER_FIREBASE_CONFIG = null;` の `null` を消して、Step 1-2 でメモした `{ ... }` をそのまま貼り付けて保存します。

```javascript
const USER_GALLERY_ID = 'my-gallery-01'; // 展覧会ごとの識別ID（半角英数字・ハイフン推奨）

const USER_FIREBASE_CONFIG = {
  apiKey: "ここにメモしたapiKeyを貼る",
  authDomain: "〇〇.firebaseapp.com",
  projectId: "〇〇",
  storageBucket: "〇〇.firebasestorage.app",
  messagingSenderId: "〇〇",
  appId: "〇〇"
};
```

> **ヒント**：複数の展覧会を同じ Firebase プロジェクトで運用したい場合は、`USER_GALLERY_ID` の文字列（例：`exhibition-2026-spring`）を変えるだけでデータを分離できます。

## Step 3：インターネットに公開して URL を発行する

書き換えた `index.html` をホスティングサービスにアップロードして公開 URL を取得します。最も簡単な **Netlify Drop** の手順を紹介します。

### 方法A：Netlify Drop を使う（もっとも簡単・おすすめ）
1. パソコン上に新しい空のフォルダ（例：`my-gallery`）を作り、その中に `index.html` を 1 つだけ入れます。
2. [Netlify Drop](https://app.netlify.com/drop) をブラウザで開きます。
3. 画面中央の点線枠に、先ほど作った **`my-gallery` フォルダごとドラッグ＆ドロップ** します。
4. 数秒待つと `https://〇〇.netlify.app` という公開 URL が発行されます。
   - ※ 無料アカウントを作成してログインしておくと、URL がずっと維持され、後から `Site configuration` で URL 名を変更することもできます。

### 方法B：その他の無料ホスティング
- **GitHub Pages**：リポジトリに `index.html` をアップロードし、Settings ＞ Pages から公開。
- **Cloudflare Pages**：フォルダをドラッグ＆ドロップするだけで高速配信・独自ドメイン対応。

## Step 4：初回ログインと運用開始

発行された公開 URL にアクセスし、ヘッダー左上のステータスが緑色の **`LIVE`** になっていればクラウド連携は成功です。

### 1. 管理者としてログインする
1. ヘッダー右上の **鍵アイコン（🔒）** をクリックします。
2. 初回デフォルトの ID / パスワードを入力してログインします。
   - **管理者ID**：`admin`
   - **パスワード**：`gallery2026`

### 2. 必ず管理者パスワードを変更する（重要）
1. ログイン後、ヘッダーに表示される **「展示・管理」** ボタンをクリックします。
2. **「展覧会・管理者設定」** タブを開きます。
3. 展覧会タイトル・サブタイトルを好みの名前に変更し、下部のフォームから **新しい管理者IDとパスワード** を設定して更新します。

### 3. 作品を展示して URL を共有する
- **「作品を展示 / 編集」** タブから画像をドラッグ＆ドロップして保存すると、鑑賞者全員の 3D 空間へリアルタイムに反映されます。
- 準備中の作品は **公開ステータスを「下書き（非公開）」** にしておくと、管理者だけに半透明プレビューが表示され、鑑賞者には空の壁として隠れます。
- 準備ができたらヘッダーの **「展覧会を共有」** ボタンで URL をコピーし、SNS やメールで案内してください。

## トラブルシューティング・よくある質問

### Q. ヘッダーのステータスが `OFFLINE` や `ERROR` になる
- **確認1**：`USER_FIREBASE_CONFIG` の末尾にセミコロン `;` やカンマ `,` の構文ミスがないか確認してください。
- **確認2**：Firebase Console で **Authentication の「匿名」が有効** になっているか確認してください。
- **確認3**：Firestore の **「ルール」** が手順通りに公開されているか確認してください。

### Q. アップロードした画像の画質や容量制限は？
- アップロード時にブラウザ側で自動的に長辺 760px・軽量 JPEG へリサイズされるため、元の画像が大きくてもそのままドラッグ＆ドロップできます。

### Q. Firebase の無料枠でどれくらい使える？
- Spark プラン（無料枠）では、Firestore の保存容量 1GB・読み取り 5万回/日・書き込み 2万回/日まで無料です。個人やグループの小〜中規模なオンライン展覧会であれば、無料枠内で十分に運用できます。
